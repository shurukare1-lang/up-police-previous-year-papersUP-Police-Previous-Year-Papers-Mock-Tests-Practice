UP Police Exam Dashboard
This repository contains a comprehensive exam preparation portal designed for candidates preparing for UP Police and various other competitive exams. It features an extensive collection of mock tests, practice tests, and question papers to help aspirants gauge their preparation levels.
Features
 * Extensive Question Bank: Access to the last 10 years of previous year question papers.
 * Mock Tests & Practice Tests: Simulated exams to improve time management and problem-solving skills.
 * Exam Coverage: Includes study materials and papers for UP Police, UP SI, CAT, PET, CTET, and more.
 * Modern & Fast Interface: Built using Vite and TypeScript for a smooth and efficient user experience.
Technologies Used
 * Vite
 * TypeScript
